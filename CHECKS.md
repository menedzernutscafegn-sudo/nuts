# Проверка NutsCafe

Повторно проверено 16 ноября 2026 года после упрощения HTML, CSS и JavaScript. Использовался Chrome на Windows. Сайт открывался напрямую по `file://`, без HTTP-сервера, установки зависимостей и сборки.

## Результат упрощения

- Сохранены шесть существующих страниц, все 16 блюд, цены, описания и основные блоки оформления.
- Удалены все запрещённые теги: `section`, `span`, `aside`, `article`, `figure`, `figcaption`, `small`, `strong`, `em`, `label`, `fieldset`, `legend`, `details`, `summary`, `picture`. Те из них, которых не было в исходной версии, также отсутствуют.
- В исходной HTML-разметке было 120 разных классов. Теперь во всех HTML, CSS и создаваемых скриптом элементах используется **14 классов**: `container`, `button`, `card`, `grid`, `heading`, `eyebrow`, `notice`, `quantity`, `panel`, `breadcrumb`, `empty`, `logo`, `actions`, `order`.
- Количество `div` в шести исходных файлах уменьшено с **310 до 253**. Убраны обёртки полей, вложенные блоки строк корзины, контейнер каталога и повторяющаяся разметка рекомендаций.
- Поля используют понятные `placeholder`, `aria-label` и прежние ограничения `required`, `minlength`, `maxlength`.
- JavaScript не ищет элементы по CSS-классам. Обновлены селекторы навигации, карточек, корзины и форм; состояние задаётся через HTML-атрибуты. Рекомендации получают сведения из существующих карточек блюд, без отдельного каталога в JavaScript.
- Раскрытие истории заказов и показ пароля работают обычными кнопками с `aria-expanded` / `aria-pressed`.
- Контрольные суммы всех 19 исходных файлов изображений совпали с версией до упрощения: фотографии и значок вкладки не изменены.
- При проверке исправлены загрузка вынесенных SVG-иконок и расположение заголовка меню на узком экране.

## Адаптивность

Для каждой из шести страниц проверены ширины **1440, 1200, 1024, 768, 480, 390 и 360 px**: всего 42 сочетания.

Во всех сочетаниях:
- нет горизонтальной прокрутки и элементов, выходящих за боковые границы окна;
- нет ошибок JavaScript и ошибок загрузки фотографий;
- локальные Manrope и Cormorant Garamond успешно загружаются.

Проверена мобильная навигация на всех шести страницах: открытие, состояние `aria-expanded`, закрытие клавишей Escape. Просмотрены снимки главной, меню и корзины на 1440/390 px, страницы блюда, входа и кабинета на 390 px.

## Контроль расчётов

Три шакшуки и один чизкейк: **1 820 ₽**.

- Зона 1: 1 820 + 199 = **2 019 ₽**.
- Зона 2: 1 820 + 299 = **2 119 ₽**.
- Зона 3: 1 820 + 399 = **2 219 ₽**.

Три шакшуки без чизкейка: **1 470 ₽**. В зоне 3 не хватает 30 ₽ до минимума; оформить нельзя. В зоне 1 успешный итог: 1 470 + 199 = **1 669 ₽**.

## Структура и доступность

- Ровно шесть HTML-страниц; один прикладной CSS и один прикладной JavaScript.
- Нет повторяющихся id, полей без подписей и несуществующих ссылок из атрибутов ARIA.
- Нет сетевых ресурсов в самих страницах: фотографии, шрифты, CSS и JS локальные.
- Данные каталога расположены в HTML, тарифы — в `data-`атрибутах `option`.
- Нет серверных обработчиков, базы данных, браузерных хранилищ и платёжной интеграции.
- Диагностика редактора не обнаружила ошибок.

## Пределы проверки

Проверка размеров выполнялась эмуляцией окна Chrome, а не на физических телефонах. Safari и Firefox отдельно не запускались. Внешние сайты не входят в проект: актуальные сведения о кафе следует проверять через карточку 2ГИС. Ресурс `neko-resto.ru` из ТЗ при разработке возвращал ошибку настройки домена; в интерфейсе нет ссылки на этот неработающий ресурс.
